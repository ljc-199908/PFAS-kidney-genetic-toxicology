# Reviewer response text for reproducibility/data availability

## Concise version

We agree that improving reproducibility convenience is important. Due to redistribution restrictions associated with third-party GWAS resources, we are unable to directly share the full pre-harmonised or harmonised SNP-level datasets. To address this, we have added a reproducibility package to the GitHub repository, including OpenGWAS outcome IDs, an exposure instrument template, a worked example script, and a one-click script that regenerates outcome-level associations and harmonised datasets from the original public resources. We also provide an example harmonised output-structure file to illustrate the expected data format. These resources enable users to reproduce the harmonisation workflow while complying with the data-use terms of the original GWAS resources.

## Slightly fuller version

We agree that improving reproducibility convenience is important. The full pre-harmonised and harmonised SNP-level datasets are derived from third-party GWAS resources, including GWAS Catalog/OpenGWAS and UK Biobank-derived summary statistics, and therefore cannot be directly redistributed in the GitHub repository. To improve reproducibility, we have added a dedicated reproducibility package containing: (i) the OpenGWAS outcome IDs used in the manuscript; (ii) a template for the PFAS exposure instruments; (iii) a worked R script that retrieves outcome associations from OpenGWAS and harmonises them with the supplied PFAS exposure instruments; and (iv) a one-click script to regenerate the analysis-ready harmonised datasets. We also included an example harmonised output-structure file to illustrate the expected data format. Together, these additions allow users to reproduce the harmonisation procedure from the original public resources while respecting resource-specific data redistribution restrictions.

## Suggested manuscript Data Availability replacement

The analysis pipeline and reproducible code supporting this study are publicly available in the GitHub repository. A permanent archived version of the repository is available through Zenodo. All data underlying the findings are derived from publicly accessible GWAS resources, including GWAS Catalog/OpenGWAS and UK Biobank-derived summary statistics. Because the full pre-harmonised and harmonised SNP-level datasets are derived from third-party GWAS resources with resource-specific redistribution terms, these datasets are not directly redistributed in the repository. Instead, we provide a dedicated reproducibility package containing OpenGWAS outcome IDs, an exposure instrument template, and one-click R scripts that retrieve the original outcome associations and regenerate the harmonised analysis-ready datasets.
